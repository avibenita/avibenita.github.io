The current version already covers the essential mapping well. I would add customization selectively—the goal should be analytical control, not a chart-design studio. Highest-priority additions 1. Quadrant definition This is the most important missing customization. X divider: Median / Mean / Custom value Y divider: Median / Mean / Custom value Show/hide divider lines Editable quadrant names, for example: High X / High Y Leaders Opportunities Monitor Low priority Optional subtle quadrant background shading Optional count and percentage in each quadrant This should appear only in Quadrant mode. 2. Axis controls Add a collapsible Axes section: Custom X and Y minimum/maximum Automatic/manual tick interval Editable axis titles Number format: decimal, percentage, currency, thousands/millions Reverse axis Show/hide gridlines Reference lines with editable value and label For GDP, formatting such as $45K or $2.1T is much more meaningful than an unexplained 45. 3. Bubble-size controls The existing single size slider is useful but insufficient. Minimum bubble diameter Maximum bubble diameter Size transformation: Area proportional Square root Logarithmic Treat negative or zero values Bubble opacity Border width Optional fixed size when no size variable is needed Keep area proportional as the default. 4. Label controls None / Hover / All should become: None Hover Selected All Automatic—show labels where space permits Additional options: Font size Label field Value appended to label Prevent overlap Allow dragging labels Label only top/bottom N Label only a selected group “Automatic” or “Selected” should probably be the default because All is already crowded in the left side of this chart. 5. Color and grouping At present, Bubble color and Group are both Region, so their roles appear duplicated. I would simplify this concept: Color by: categorical or continuous variable Separate series by: optional categorical variable Then add: Palette selector Color-blind-safe palette as default Custom category colors Continuous color gradient and color scale Opacity Show/hide legend Legend position If Color and Series use the same field, Statistico should detect that and avoid redundant behavior. Very useful interactive features Click a bubble to select it Ctrl-click for multiple selection Selected only / Fade others Lasso or rectangle selection Filter by clicking legend categories Search that zooms to or strongly highlights the result Reset view button Zoom and pan Write selected rows back to Excel Exclude selected observations temporarily The search field currently says Label / ID?; an explicit ID mapping field may therefore be useful. Analytical overlays Put these in a separate collapsible Analysis section: Linear or LOESS trend line Confidence band Correlation and R 2 Marginal distributions or rugs Mean/median reference lines User-defined benchmark lines Highlight outliers Optional convex hull or ellipse around groups For the quadrant chart, I would avoid showing regression by default. It should remain an optional layer. Presentation customization A compact Appearance popover could contain: Chart title and subtitle Light/dark background Plot background Font size Bubble opacity Gridline strength Chart aspect ratio Legend position Export dimensions These are useful, but less important than quadrant, axis, size, and label controls. Recommended sidebar structure Instead of showing every option simultaneously: Variables Quadrants — only in Quadrant mode Axes Bubbles Labels Analysis Appearance Export Keep the first two open and the rest collapsed. This preserves the clean interface. Specific corrections visible in the screenshot STATISTICO? and area ? GDP appear to contain broken icon characters or encoding errors. The label Size represents ? GDP (AREA) has the same issue. Bubble color and Group need clearer distinction—or consolidation. The size legend overlaps the plot and obscures low-X values; place it outside the plotting area or make it movable. The quadrant lines are labeled “Median X/Y,” but users should see the actual values too: Median X = 15.4, Median Y = 76.9. The quadrants themselves need names or light shading; otherwise it still reads mainly as a bubble chart with two dashed lines. The upper badges consume space without offering much action. They could be reduced to a single data summary line. Add visible Reset, Export, and Fullscreen controls rather than relying only on the Highcharts hamburger menu. For the next iteration, I would prioritize exactly five changes: custom quadrant thresholds and names, automatic labels, axis formatting, stronger selection/highlighting, and moving the bubble-size legend outside the plot.
