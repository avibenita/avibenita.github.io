Interactive workflow

One analysis. Six connected views.

Click a stage to inspect it — each view stays inside the same fitted solution, so there's no re-running the analysis to move between them.

Suitability

KMO and Bartlett's test give an adequacy verdict before extraction even runs, with the correlation matrix and determinant available for a first look at redundancy between variables.

Extraction

The eigenvalue table and an interactive scree plot pair with Kaiser-criterion retention guidance, so how many factors to keep is a visible decision, not a hidden default.

Rotation

Switch between Varimax, Promax, and Oblimin and watch the loadings matrix and heatmap update, with cross-loading counts and a factor correlation (Phi) matrix when rotation is oblique.

Interpretation

Each retained factor is shown with its defining variables, variance explained, and composite reliability (Ω), plus an AI-suggested name badge to test against your own theory. Cross-loading variables without a clear home are flagged separately, and an expandable AI Details panel adds the full naming rationale and plain-language model summary — see caution below.

Diagnostics

Communalities, uniqueness, an RMSR-based fit index, and Heywood-case flags surface whether the rotated solution is well-behaved before it gets used further.

Scores

Case-wise factor scores, a score distribution histogram, and a two-factor score map with outlier detection connect the rotated solution back to individual cases.

Structure

Rotation is part of the model workflow

The rotated loadings matrix sits next to a switchable rotation method and an adjustable loading threshold — changing either updates the heatmap and cross-loading count together, making the structure decision visible rather than fixed.

Scores

Move from rotated loadings to case-level scores

Regression-method factor scores connect back to the rotated solution, so the score table, score distribution, and two-factor score map stay tied to the same fitted model — no re-running the analysis to move between them.

Interpretation

Naming factors is part of the analytical workflow

The Interpretation view pairs each factor's defining variables, variance explained, and composite reliability with an AI-suggested name — and an expandable AI Details panel adds a plain-language summary of structure, variance, and model quality, drawing on the same fit statistics already in the workspace.

AI-suggested names are hypotheses to check against theory, not statistical results — they support, but do not replace, statistical judgment.
