The practical benefits of scripting—without writing scripts

Statistico does not include a scripting language or macro environment in the tradition of SPSS syntax or Minitab macros. That is not a gap to apologize for. Most analysts use those tools for a handful of practical jobs: run the same analysis again, apply the same preparation rules to updated data, and keep the work consistent and reviewable. Statistico delivers those jobs as guided, interactive workflows.

The claim, stated carefully

Statistico delivers the scripting benefits most users actually need, through guided and interactive workflows. It is not merely an Excel add-in of isolated procedures — it is an interactive statistical system built around Excel, with reusable workflows replacing much of the syntax burden found in traditional software.

What this is — and is not

Scripting also supports arbitrary programming: loops, branching, batch processing, and custom extensions. Statistico does not claim those capabilities. A more defensible — and more useful — position is this:

Statistico delivers the scripting benefits most users actually need, through guided and interactive workflows. Repeat the analysis. Keep preparation consistent. Filter and trim in view. Review the rules without reading code.

An interactive system, not isolated procedures

Statistico is built around Excel as a live statistical workspace: explore, diagnose, and refine in the same place the data already lives. Reusable Workflows are how that work survives the next dataset — and the next colleague.
