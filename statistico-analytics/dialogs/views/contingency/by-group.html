Similarity Profile™

How to read Similarity Profile™ for frequencies and crosstabs by group.

This is a practical, non-academic approach original to Statistico. It is not a published coefficient, not a p-value, and not a substitute for a homogeneity or interaction test. Use it to describe how alike group association structures look in applied work.

What it is for

After you split the same row×column table by a grouping column, Similarity Profile™ asks: which groups share the same association structure, and which stand apart? It compares every pair of group levels (Overall omitted) on pattern, strength, and residual sign, then rates them from 0 to 100.

The three components

Pattern — do the same cells stand out? Tucker congruence of aligned adjusted residuals.
Strength — is Cramér’s V similar across groups?
Sign — do cells agree on over- vs under-representation (or both stay near independence, |residual| < 1)?
Overall combines the three with a geometric mean, so one weak component is not hidden by two strong ones.

How to read the scores

90–100 Very similar
75–89 Mostly similar
50–74 Mixed similarity
Below 50 Substantially different
Click a heatmap cell or table row to see why a pair scored that way. The scatter plots each cell’s adjusted residual in one group against the other; the diagonal is a perfect match.

What it is not

It does not test whether the association differs significantly between groups. Treat these scores as an effect-size style description of practical similarity, designed here for Statistico.
