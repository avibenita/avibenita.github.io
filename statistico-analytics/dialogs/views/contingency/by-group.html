Group charts

How to read Distribution and Association pattern.

Each panel is the same row×column table inside one group. Panels share one scale so colour and height mean the same thing in every group. These charts describe each group. They do not test whether the association differs between groups.

Distribution

Each column is 100% stacked. The segments are the row variable’s share within that column category. Compare the same column across panels: a taller segment means that row level is a larger share of the column in that group.

Association pattern

Each cell is an adjusted residual: how many more or fewer cases that cell has than independence would predict inside that group.
Orange — more cases than expected (positive residual).
Blue — fewer cases than expected (negative residual).
Pale — close to independence (residual near 0).
The ± number in the caption is the shared colour scale. The same shade is the same size of departure in every panel. A value around 2, positive or negative, is a large departure within that group.

What it is not

A strong colour in one group does not, by itself, mean that group differs from another. Use Similarity Profile™ to compare association structure across groups. That comparison is descriptive, not a significance test.

Similarity Profile™

How to read Similarity Profile™ for frequencies and crosstabs by group.

This is a practical, non-academic approach original to Statistico. It is not a published coefficient, not a p-value, and not a substitute for a homogeneity or interaction test. Use it to describe how alike group association structures look in applied work.

What it is for

After you split the same row×column table by a grouping column, Similarity Profile™ asks: which groups share the same association structure, and which stand apart? It compares every pair of group levels (Overall omitted) on pattern, strength, and residual sign, then rates them from 0 to 100.

The three components

Pattern — do the same cells stand out? Tucker congruence of aligned adjusted residuals.
Strength — is Cramér’s V similar across groups?
Sign — do cells agree on over- vs under-representation (or both stay near independence, |residual| < 1)?
Overall combines the three with a geometric mean, so one weak component is not hidden by two strong ones.

How to read the scores

90–100 Very similar
75–89 Mostly similar
50–74 Mixed similarity
Below 50 Substantially different
Click a table row to see why a pair scored that way. The chart overlays each group’s adjusted residuals, or each group’s column %, on one shared scale.

What it is not

It does not test whether the association differs significantly between groups. Treat these scores as an effect-size style description of practical similarity, designed here for Statistico.
