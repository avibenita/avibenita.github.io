How to use this calculator

Type four counts. Nothing is read from a worksheet, and the cells start empty. The headline updates as you edit.

The table

Each row is a group and each column is an outcome. Type a count in each cell. Switch the view among counts, row percentages, and expected counts. Hover a cell to see its observed count, expected count, and contribution to χ².

Group of interest and event

The headline, risk ratio, and odds ratio compare the group of interest with the other row, for the column you mark as the event. Changing either control reverses the direction of the comparison.

How the data were collected

Independent groups. Each person is in one group, so row percentages estimate risk. Type this table:

The headline is “40% versus 20% · 20 percentage points higher”. The risk ratio is 2 and the odds ratio is 2.67.

Case–control. Cases and controls were sampled separately, so report the odds ratio and not a risk ratio. Type this table:

ExposedUnexposedTotal
Cases4060100
Controls2080100

The odds ratio is 2.67. The 40% and 20% shares describe the samples, not population risks.

Paired before / after. The same people were measured twice. McNemar’s test uses only the pairs that changed. Type this table:

Scenario

After both counts in a row are typed, change that row’s event count. The row total stays fixed and the other cell adjusts. A Scenario label appears. Reset returns to the counts from your last direct edit.

From the independent example, change Group A’s event count from 40 to 50. No event in that row becomes 50, because the row total stays 100:

EventNo eventTotal
Group A5050100
Group B2080100

The headline becomes “50% versus 20% · 30 percentage points higher”.

Which p-value

The card marked “Use this” is the one to report. When expected counts are small, that is Fisher’s exact test. The i beside each metric explains what that number is.
