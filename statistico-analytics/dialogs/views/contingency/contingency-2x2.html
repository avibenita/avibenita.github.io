How to use this calculator

Type four counts. Nothing is read from a worksheet. The headline updates as you edit.

The table

Each row is a group and each column is an outcome. Use the steppers or type a count. Switch the view among counts, row percentages, and expected counts. Hover a cell to see its observed count, expected count, and contribution to χ².

Group of interest and event

The headline, risk ratio, and odds ratio compare the group of interest with the other row, for the column you mark as the event. Changing either control reverses the direction of the comparison.

How the data were collected

Independent groups — each person is in one group. Row percentages estimate the event risk, so the risk difference and risk ratio are reported.

Case–control — cases and controls were sampled separately. The odds ratio is reported. Row percentages are not population risks, and a risk ratio is not shown.

Paired before / after — the same people were measured twice. McNemar’s test uses the discordant pairs. Pearson χ² and Fisher’s exact test are not used.

Scenario

Change the event count in one group while keeping that group’s total fixed. A Scenario label appears. Reset returns to the counts from your last direct edit.

Which p-value

The card marked “Use this” is the one to report. When expected counts are small, that is Fisher’s exact test. The i beside each metric explains what that number is.
