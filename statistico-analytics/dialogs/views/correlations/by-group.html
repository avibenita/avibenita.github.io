Similarity Profile™

How to read Similarity Profile™ for correlations by group.

This is a practical, non-academic approach original to Statistico. It is not a published coefficient, not a p-value, and not a substitute for a significance test. Use it to describe how alike group correlation structures look in applied work.

What it is for

After you split pairwise correlations by a grouping column, Similarity Profile™ asks: which groups share the same association structure, and which stand apart? It compares every pair of groups on pattern, strength, and sign, then rates them from 0 to 100.

The three components

Pattern — do the same variable pairs go together? Tucker congruence of the aligned r-vectors.
Strength — are associations similarly strong (mean |r|)?
Sign — do pairs agree on direction (positive, negative, or both weak)?
Overall combines the three with a geometric mean, so one weak component is not hidden by two strong ones.

How to read the scores

90–100 Very similar
75–89 Mostly similar
50–74 Mixed similarity
Below 50 Substantially different
Click a table row to see why a pair scored that way. Open Congruence scatter from the pair profile; the plot is each variable pair’s r in one group against the other, and the diagonal is a perfect match.

What it is not

It does not test whether two correlation matrices differ significantly. Treat these scores as an effect-size style description of practical similarity, designed here for Statistico.
